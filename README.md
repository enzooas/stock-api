# Stock API

API REST de controle de estoque desenvolvida com Spring Boot.

## Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven

## Funcionalidades

- Listar produtos
- Cadastrar produtos
- Atualizar produtos
- Deletar produtos

## Endpoints

GET /produtos

POST /produtos

PUT /produtos/{id}

DELETE /produtos/{id}

## Objetivo

Projeto desenvolvido para praticar CRUD e APIs REST com Spring Boot.
