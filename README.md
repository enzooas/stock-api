# Stock API

Inventory management REST API developed with Spring Boot.

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven

## Features

- Create products
- Read products
- Update products
- Delete products

## Endpoints

GET /produtos

POST /produtos

PUT /produtos/{id}

DELETE /produtos/{id}

## Objective

Project developed to practice CRUD and REST APIs with Spring Boot.
